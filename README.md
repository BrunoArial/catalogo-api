# Catálogo API

API em desenvolvimento para gerenciar um catálogo de produtos, criada como projeto de estudo de Java Back-End com Spring Boot.

O objetivo é aplicar conceitos de HTTP e REST, injeção de dependência, organização em camadas e testes automatizados. Ao longo do desenvolvimento, a aplicação será integrada ao PostgreSQL utilizando JPA/Hibernate.

## Tecnologias

- Java 25
- Spring Boot
- Maven
- Git e GitHub
